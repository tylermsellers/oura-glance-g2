Oura Glance

Oura Glance is a personal, hobby project that surfaces your Oura Ring Readiness, Sleep, and Activity data on Even Realities G2 smart glasses (and a companion phone view), using the official Oura API.

It is not affiliated with, endorsed by, or officially supported by Oura Health Oy or Even Realities.

Get it

Oura Glance is distributed as a sideloaded package from GitHub Releases — see the project README for installation instructions.
